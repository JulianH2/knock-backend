## 3. Descripción

Desde una solicitud nueva o desde el chat. La primera vez que cotiza se le ofrece verificarse (se puede omitir).

## 4. Alcance

- Precio fijo o rango (mínimo y máximo).
- Día y hora propuestos.
- Nota.
- Oferta de verificación la primera vez.

## 5. Fuera de alcance

- Borrador con IA (HU-059).
- Editar o retirar (HU-035).
